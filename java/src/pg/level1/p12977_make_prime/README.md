# 소수 만들기
# 링크 
https://school.programmers.co.kr/learn/courses/30/lessons/12977?language=java

## 접근
- 서로 다른 숫자 3개를 선택해야 한다. 처음에는 정렬이 필요하다고 생각했다.
- 조합이므로 선택한 인덱스가 이전 인덱스보다 뒤에 있도록 탐색했다.
- 세 수의 합을 구한 뒤 소수 여부를 판별한다.
- 3개의 수를 선택하기 위해 삼중 반복문을 생각했다.

## 소수 판별
처음에는 2부터 q/2까지 확인하려 했다.
약수는 쌍으로 존재하므로 √q까지만 확인하면 된다는 것을 알게 됐다.

## 실수
- 처음에 i + j + k로 인덱스를 더했다.
- j, k 시작점을 고정해서 중복 조합이 발생했다.
- 반복문의 마지막 인덱스 범위를 잘못 잡았다.

## 복잡도
- 조합 탐색: O(n³)
- 각 합의 소수 판별: O(√q)
